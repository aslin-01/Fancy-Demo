# Madha Fancy — Luxury Admin Frontend

A royal, state-of-the-art Admin Management Portal built for Madha Fancy.

## Features
- **Royal Aesthetic**: Tailored deep amber gold and warm ivory palette matching the official website.
- **Unified Design System**: Clean typography with Cormorant Garamond, Great Vibes, and Jost.
- **Real-Time KPIs**: Track total revenue, order count, active products, and patron growth.
- **Visual Analytics**: Interactive Recharts revenue trend area chart and order fulfillment distribution.
- **Product Management**: Full catalog controls for handwoven sarees (Name, SKU, Fabric, Category, Occasions, Price, MRP, Stock Count, Image URL).
- **Order Fulfillment**: Live status update (Pending, Processing, Shipped, Delivered, Cancelled) and invoice inspection.
- **Customer Directory**: Customer spending metrics and contact information.
- **Instant Demo Login**: 1-click test button pre-filling Super Admin credentials.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
   Admin Portal runs at **http://localhost:5174**

3. Default Admin Credentials:
   - **Email**: `admin@madhafancy.com`
   - **Password**: `admin123`
